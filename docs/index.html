Early development: Khwarizmi Studio is an engineering-focused project based on AFFiNE. The capabilities described here represent the product direction, not a claim that they are already implemented.
The product vision

One workspace. The whole calculation.

Engineering work should communicate not only the answer, but how that answer was reached—and give another engineer enough context to review it.

01 / CALCULATE

Calculation worksheets

Define variables, parameters, and units. Write equations, evaluate them in sequence, and keep intermediate values available for reuse.

02 / COMPOSE

Visual, flexible layout

Bring equations, explanations, input data, tables, and diagrams together. Arrange content in sections and columns to suit the engineering task.

03 / COMMUNICATE

Reviewable documentation

Connect assumptions, inputs, substitutions, checks, and conclusions in a durable document designed for technical review and eventual PDF delivery.

Guiding principles

Show the work. Keep it reviewable.

The project is being shaped around the needs of engineers who prepare and check real technical calculations.

Show every meaningful stepDisplay substitutions and intermediate results, not just a final number.
Keep the context togetherPlace equations, assumptions, explanatory text, tables, and diagrams in one document.
Treat units as first-classQuantities, conversions, and dimensional consistency belong in the calculation model.
Separate presentation and computationKeep the worksheet experience distinct from the calculation engine that evaluates it.
Development roadmap

Built in deliberate stages.

Architecture and verification come before broad feature implementation. Follow the linked plan for detailed tasks and exit criteria.

Phase 0

Repository foundation

Establish the AFFiNE-derived baseline, provenance, licensing, and reproducible builds.

Phase 1

Architecture contracts

Specify the document model, calculation semantics, units, host boundary, and RPC contract.

Phase 2

Worksheet experience

Build page-oriented editing, flexible composition, content blocks, and persistence.

Phase 3

Calculation and traceability

Evaluate expressions and expose dependencies, substitutions, reusable results, and errors.

Phase 4

Engineering verification

Develop representative examples, documented scopes, benchmark cases, and independent checks.

Phase 5

Output and release

Deliver paginated documents, PDF export, installation checks, and release guidance.

Built on open source

An engineering-focused adaptation based on AFFiNE.

Khwarizmi reuses AFFiNE as its inherited application foundation and BlockSuite as its editor foundation. The engineering worksheet model and calculation behavior are intended to become project-owned layers. Upstream licenses and notices are preserved.
